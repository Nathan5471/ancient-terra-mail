# Ancient Terra Mail

Ancient Terra Mail is a game where you try to run the TPS building from Terra. Your goal is to deliver all of the mail and not let the queue overflow. You can buy upgrades that help you or make the game more difficult and fun.

## How to play

Your goal is to deliver the mail to the correct mailbox. Click on the first letter that shows up and then click on the correct mailbox. Once you have enough money, you can start buying upgrades. You lose if your queue overflows. Check it out at [https://nathan5471.itch.io/ancient-terra-mail](https://nathan5471.itch.io/ancient-terra-mail)

## Features

* Moveable letters
* Upgrades
* Start and end screen

## Technologies

I built this in Godot

## Assets

I made all of the assets except the Poobert on the start page. The assets I made are based on the design for the TPS building in Terra
